# script/ — сценарии для телесуфлёра

Сюда кладутся тексты роликов **в формате Markdown** — их читает плагин OBS
[obs-teleprompter](https://github.com/filiphric/obs-teleprompter) (меню **Tools → Teleprompter**,
там выбирается эта папка).

## Как пользоваться

1. Создать файл `ГГГГ-ММ-ДД тема.md` и вставить текст.
2. В OBS: **Tools → Teleprompter** → выбрать папку `script\` → выбрать файл.
3. Снимать, читая с экрана.

## Соглашение об именах

```
2026-10-20 контент-завод-обзор.md
2026-10-27 разбор-портфеля.md
```

Имя файла = дата съёмки + тема. Оно же потом используется как `--label` при монтаже,
чтобы прогон и сценарий было легко сопоставить.

## Важно про конфиденциальность

Тексты сценариев **не попадают в git** (см. правила в `.gitignore`): этот репозиторий публичный,
а сценарии — рабочий материал. В репозитории живут только этот README и `.gitkeep`.

## Про сам монтаж

Автомонтаж сценарий **пока не читает** — ему нужен только видеофайл. Сценарий сегодня нужен
телесуфлёру. Сверка расшифровки со сценарием (§3.4 спецификации) ещё не реализована; когда будет —
она возьмёт отсюда текст автоматически.
